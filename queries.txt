Component Code Audit — site refresh queries
===========================================


AUTOMATED REFRESH
-----------------
Run this from the private repository's build directory:

  python3 update_site.py <site-id> --cookie-file /path/to/cookies.txt

One-time dependency setup (the updater will automatically use build/.venv):

  python3 -m venv .venv
  .venv/bin/python -m pip install -r requirements.txt

For example:

  python3 update_site.py georgia-power --cookie-file ~/Downloads/cookies.txt
  python3 update_site.py alabama-power --print-urls
  python3 update_site.py

Omit the site id for an interactive menu. The updater calls
https://author.southerncompany.com, runs the five component queries in order, and
waits 5 seconds between requests. It validates all five responses before replacing
build/raw/<site-id>/, rebuilds freeforms.json and analysis.json, and copies those two
encrypted files to the sibling gpc-freeform-audit checkout.

Use --no-build to fetch only, --no-sync to rebuild only the private checkout, or
--delay N to override the 5-second interval. --print-urls performs no requests.


AUTHENTICATION
--------------
The author is normally SSO-protected. Supply a current authenticated browser session
using one of these methods:

  --cookie-file FILE   Netscape-format cookies.txt exported from the logged-in browser
  AEM_COOKIE='...'     the Cookie request header copied from browser developer tools

The cookie value is intentionally not stored in the project. HTTP Basic auth is also
available with PROD_USERNAME and PROD_PASSWORD (or AEM_USER and AEM_PASSWORD), plus
the --basic-user and --basic-password command-line options.

If your shell already exports the production variables, no authentication arguments
are needed:

  export PROD_USERNAME="sbadon"
  export PROD_PASSWORD
  python3 update_site.py alabama-power
If AEM returns a login page, the updater stops without replacing the site's previous
exports.

COMPONENT EXPORTS
-----------------

  filename                 resource type                                  content property
  freeform.json            global/components/content/freeform              text
  contentcard.json         global/components/content/contentcard           text
  herobanner.json          global/components/content/herobanner            description
  textoverimage.json       global/components/content/textoverimage         text
  thumbnailwithtext.json   global/components/content/thumbnailwithtext     desc

Every response must have success: true, more: false, offset: 0, and results/total
matching the hits array. Empty results are valid. String-array content properties are
supported and retain indexed field names in the audit.


MANUAL QUERY TEMPLATE
---------------------
Replace SITE_PATH, RESOURCE_TYPE, and CONTENT_PROPERTY:

  https://author.southerncompany.com/bin/querybuilder.json?type=nt:unstructured&path=SITE_PATH&property=sling:resourceType&property.value=RESOURCE_TYPE&p.limit=-1&p.hits=selective&p.properties=jcr:path%20CONTENT_PROPERTY

Freeform example for Georgia Power:

  https://author.southerncompany.com/bin/querybuilder.json?type=nt:unstructured&path=/content/georgia-power&property=sling:resourceType&property.value=global/components/content/freeform&p.limit=-1&p.hits=selective&p.properties=jcr:path%20text

Use an author environment, not publish. Author includes draft and unpublished content.
Log in first and run manual URLs in the same browser session.


WHY THE PARAMETERS MATTER
-------------------------

type=nt:unstructured
  Restricts traversal to component nodes instead of every node type.

path=<site content path>
  Keeps one refresh isolated to the selected site's subtree. The updater also rejects
  any returned path outside that boundary.

property=sling:resourceType
property.value=<component resource type>
  Selects the exact component implementation. Node names are not used to infer type.

p.limit=-1
  Prevents the default ten-result cap. The updater rejects truncated responses.

p.hits=selective
p.properties=jcr:path%20<content property>
  Returns only the stable node identity and complete authored source needed by the
  audit. Flags, notes, and snapshots remain keyed by jcr:path across refreshes.


STORAGE AND SAFETY
------------------
Raw responses are plaintext authored content and belong only in the private repository.
The public repository receives encrypted freeforms.json and analysis.json, never
build/raw/, update_site.py, sites.json, or build.py. A failed query leaves the previous
five-file site batch in place.
